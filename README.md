# Aqua Frank — односторінковий магазин

Сайт відтворює сценарій замовлення Telegram-бота: каталог, кошик із зміною кількості, акцію для нових клієнтів, оптові ціни, заставу за нову тару та покрокове оформлення. Під час замовлення клієнт обирає орієнтовний час доставки (до 13:00 або до 17:00) і за потреби залишає коментар для кур'єра.

## Запуск

У папці проєкту виконайте:

```powershell
npm start
```

Потім перейдіть на `http://localhost:4173`. Порт можна змінити через змінну `PORT` (на Railway її задає платформа). `npm start` запускає `node server.js`.

## Примітка про замовлення

Кошик і історія замовлень клієнта зберігаються в `localStorage`. Запущений `server.js` записує кожну заявку у `data/orders.ndjson`.

Заявки надсилаються в чат Aqua Frank `-1004380997543`. Перед запуском задайте лише токен бота — він не записується у код:

```powershell
$env:TELEGRAM_BOT_TOKEN = "токен_вашого_бота"
npm start
```

У production на Railway додайте `TELEGRAM_BOT_TOKEN` як змінну сервісу (Variables). Без токена заявки лише зберігаються у `data/orders.ndjson`, а Telegram пропускається.

За потреби можна змінити чат через `$env:TELEGRAM_CHAT_ID` перед запуском.

Якщо відкрити `index.html` напряму без сервера, усі інтерфейсні сценарії працюватимуть, але заявка залишиться лише в цьому браузері.
