# Aqua Frank — односторінковий магазин

Сайт відтворює сценарій замовлення Telegram-бота: каталог, кошик із зміною кількості, акцію для нових клієнтів, оптові ціни, заставу за нову тару та покрокове оформлення. Під час замовлення клієнт обирає орієнтовний час доставки (до 13:00 або до 17:00) і за потреби залишає коментар для кур'єра.

## Запуск

У папці проєкту виконайте:

```powershell
node server.js
```

Потім перейдіть на `http://localhost:4173`.

## Примітка про замовлення

Кошик і історія замовлень клієнта зберігаються в `localStorage`. Запущений `server.js` записує кожну заявку у `data/orders.ndjson`.

Заявки надсилаються в чат Aqua Frank `-1004380997543`. Щоб увімкнути Telegram без файла `.env`:

1. Створіть бота через [@BotFather](https://t.me/BotFather) командою `/newbot` і скопіюйте виданий токен.
2. Додайте бота до Telegram-групи Aqua Frank і переконайтеся, що він може надсилати повідомлення.
3. Створіть локальний файл конфігурації з шаблону:

```powershell
Copy-Item telegram-config.example.json telegram-config.json
notepad telegram-config.json
```

4. Замініть `PASTE_BOT_TOKEN_HERE` на токен бота та збережіть файл. Приклад вмісту:

```json
{
  "telegramBotToken": "PASTE_BOT_TOKEN_HERE",
  "telegramChatId": "-1004380997543"
}
```

5. Перезапустіть сервер командою `node server.js`.

Файл `telegram-config.json` виключений через `.gitignore`: не завантажуйте його на GitHub і не надсилайте нікому. У репозиторій можна додавати лише `telegram-config.example.json`, у якому немає справжнього токена. Для хостингу замість локального файла можна задати секретні змінні `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID` у налаштуваннях середовища хостингу.

Без токена заявки й надалі зберігатимуться у `data/orders.ndjson`, але не надсилатимуться в Telegram. Якщо відкрити `index.html` напряму без сервера, заявки не будуть надсилатися на сервер.
