# Aqua Frank — односторінковий магазин

Сайт відтворює сценарій замовлення Telegram-бота: каталог, кошик із зміною кількості, акцію для нових клієнтів, оптові ціни, заставу за нову тару та покрокове оформлення. Під час замовлення клієнт обирає орієнтовний час доставки (до 13:00 або до 17:00) і за потреби залишає коментар для кур'єра.

## Запуск

У папці проєкту виконайте:

```powershell
node server.js
```

Потім перейдіть на `http://localhost:4173`.

## Примітка про замовлення

Кошик і історія замовлень клієнта зберігаються в `localStorage`. Запущений `server.js` записує кожну заявку у `data/orders.ndjson`.

Заявки надсилаються в чат Aqua Frank `-1004380997543`. Щоб увімкнути Telegram:

1. Створіть бота через [@BotFather](https://t.me/BotFather) командою `/newbot` та скопіюйте виданий токен.
2. Додайте бота до Telegram-групи Aqua Frank і переконайтеся, що він може надсилати повідомлення.
3. Скопіюйте `.env.example` у `.env` та відкрийте `.env` у текстовому редакторі:

```powershell
Copy-Item .env.example .env
notepad .env
```

4. Вставте токен після `TELEGRAM_BOT_TOKEN=` і збережіть файл. ID чату вже вказаний; змінюйте `TELEGRAM_CHAT_ID` лише якщо використовуєте іншу групу.
5. Перезапустіть сервер:

```powershell
node server.js
```

Файл `.env` зберігається тільки локально і не додається до ZIP/репозиторію. Не надсилайте токен у чат і не публікуйте його. Без токена заявки й надалі зберігатимуться у `data/orders.ndjson`, але не надсилатимуться в Telegram.

Якщо відкрити `index.html` напряму без сервера, усі інтерфейсні сценарії працюватимуть, але заявка залишиться лише в цьому браузері.
